# MTU 趋势下滑归因分析

本项目针对 K 交易所（虚构平台）W14-W22 的 MTU 趋势下滑进行业务归因，依次完成异常时点定位、用户池流入/流出拆解、用户层级下钻、国家与注册批次定位，并提出止血、召回与预警机制建议。

> 数据均经过脱敏和虚构处理，与真实业务无关。`user_event_detail` 为全平台 20% 明细样本，样本交易金额仅用于比较价值特征，不代表全平台交易损失。

## 核心结论

- **W16 是流失侧预警点**：转沉默人数环比增长约 **49.4%**。
- **W17 是核心恶化拐点**：MTU 由 20.39 万降至 19.38 万，周环比为 **-4.95%**。
- W16 到 W17，首交流入增加 5,380 人，但召回减少 3,828 人、转沉默增加 10,109 人，主要矛盾是存量流失与召回下降，而非单纯拉新不足。
- 异常增量主要集中在重度用户；20% 明细样本进一步定位到 **D 国 × 重度用户 × 存量老客**。
- 建议优先开展重点客群止血与根因排查、分层召回，并将转沉默、净流量和重点客群变化纳入 MTU 前置预警。

## 分析框架

```text
异常定位 -> 用户池拆解 -> Tier 下钻 -> Country 下钻
-> 注册批次识别 -> 核心客群定位 -> 业务动作与预警机制
```

业务解释公式：

```text
MTU 变化 ≈ 首交流入 + 召回流入 - 转沉默 + ε
```

其中 `ε` 代表统计时点、状态判定或未纳入因素造成的差异；该公式用于解释变化方向，不作为严格会计恒等式。
